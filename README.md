### 🔥 Multimodal Gas Leakage Detection — *142 Citations* - Symbiosis Centre of Applied Artificial Intelligence
> **Published Research · Edge Inference · CNN + LSTM**

Designed and deployed a **CNN+LSTM pipeline** fusing thermal camera imagery with live Arduino sensor streams (gas, temperature, humidity) for real-time hazardous gas detection on a **Raspberry Pi**. Achieved **96% accuracy — 12–18% above all baselines**. Published in *Applied System Innovation*.

Also created and open-sourced the **MultimodalGasData dataset**, now cited **39 times** independently — used by research groups worldwide as a benchmark.

`PyTorch` `CNN` `LSTM` `Multimodal Fusion` `Edge Inference` `Raspberry Pi` `Arduino`

### 🧠 Adversarial ML Defense Research: Cryptography and Network Security

Built structured evaluation protocols with controlled perturbation budgets and documented failure modes.

`Adversarial ML` `FGSM` `C&W` `BPDA` `Feature Distillation` `Model Robustness`
